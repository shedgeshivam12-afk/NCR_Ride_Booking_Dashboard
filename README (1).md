# NCR Ride Booking Analytics Dashboard

An Excel-based data analytics project that explores ride-booking
operations, revenue, vehicle performance, and customer/driver ratings
using an NCR ride-bookings dataset.

## Project Overview

This project presents an interactive Excel dashboard built to summarize
ride-booking data and make key operational metrics easier to understand.
The workbook is organized into four dashboard views:

1.  **Overall Dashboard** -- High-level booking performance, booking
    status, vehicle-wise bookings, and ride volume over time.
2.  **Vehicle Type Dashboard** -- Vehicle-wise booking analysis and
    distance travelled.
3.  **Revenue Analytics** -- Revenue analysis by payment method, vehicle
    type, booking status, and monthly trend.
4.  **Rating Analytics** -- Customer and driver rating analysis,
    including rating comparisons and distributions.

## Dashboard Features

-   KPI cards for quick performance summaries
-   PivotTable-based analysis
-   Interactive slicers and date timeline filters
-   Charts for booking trends, vehicle types, revenue, and ratings
-   Separate dashboard sheets for focused analysis

## Tools Used

-   Microsoft Excel
-   PivotTables and PivotCharts
-   Excel slicers and timeline
-   Spreadsheet formulas

## How to Use

1.  Download `NCR_Ride_Booking_Dashboard.xlsx`.
2.  Open the workbook in Microsoft Excel.
3.  Navigate through the four dashboard sheets.
4.  Use the slicers and date timeline to filter the dashboard views.
5.  Review the charts and KPI cards to explore the booking data.
